# 🛒 E-commerce App - Flutter

A feature-rich Flutter application for online shopping, featuring product discovery, category browsing, and a seamless cart management system. This app follows Clean Architecture principles and uses BLoC for efficient state management.

---

## ✨ Features

- **🏠 Home Screen**:
  - **Dynamic Banners**: Interactive sliders showcasing featured products and offers.
  - **Categories**: Browse products by specific departments and categories.
  - **Most Selling Products**: Explore trending and popular items.
- **🔍 Search**: Quickly find products with a real-time search interface.
- **🛒 Shopping Cart**:
  - Add or remove items with real-time price calculation.
  - Manage product quantities easily.
- **📌 Wishlist**:
  - Save your favorite items for later.
  - Persistent storage and easy management of saved products.
- **ℹ️ Product Details**: 
  - Comprehensive details for each item (Description, price, images).
  - High-quality image slideshows for product inspection.
- **🔐 Authentication**:
  - Secure Login and Sign-up screens.
  - Token-based session management for a personalized experience.
- **🎨 Modern UI/UX**:
  - Professional design with responsive layouts for different screen sizes.
  - Smooth transitions and interactive elements using `flutter_screenutil`.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev/) (Dart)
- **State Management**: [BLoC](https://pub.dev/packages/flutter_bloc)
- **Architecture**: Clean Architecture (Data, Domain, Presentation)
- **Dependency Injection**: [GetIt](https://pub.dev/packages/get_it) & [Injectable](https://pub.dev/packages/injectable)
- **Networking**: [HTTP](https://pub.dev/packages/http)
- **Libraries & Plugins**:
  - `flutter_bloc`: For robust state management.
  - `flutter_screenutil`: For adaptive UI across various devices.
  - `flutter_image_slideshow`: For attractive product image carousels.
  - `cached_network_image`: For efficient remote image loading.
  - `dartz`: For functional error handling.
  - `shared_preferences`: For local data persistence.
